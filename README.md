# Sanchari World — Responsive Travel Website

A responsive travel and tourism website for exploring destinations, holiday packages, and vehicle rentals.

## Features
- **Responsive Sticky Navigation & Mobile Menu**: Clean, fluid navigation across all screen sizes.
- **Top Destinations Showcase**: Interactive destination cycling carousel.
- **Trip Search Bar**: Quick enquiry search connecting directly to bookings.
- **Vehicle Fleet & Video Previews**: Interactive preview cards with smooth transitions.
- **Curated Tour Packages**: Categorized filters for adventure, beach, culture, and nature.
- **Enquiry & Contact Integration**: Direct WhatsApp chat shortcut and pre-filled email enquiry forms.

## Tech Stack
- HTML5 & Modern Semantic Elements
- CSS3 (Flexbox, Grid, CSS Variables, Responsive Design)
- Vanilla JavaScript (Intersection Observer, Local Storage, Dynamic Filtering)

## Local Development
Run a local static server:
```bash
python3 -m http.server 3000
# or
npx serve .
```
Then open `http://localhost:3000` in your browser.

## Deployment
Deployed seamlessly on [Vercel](https://vercel.com).
